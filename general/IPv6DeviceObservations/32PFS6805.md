# Philips 32PFS6805/12 (Saphi OS)

- Uses SLAAC for IPv6
- Does not use DHCPv6
- If no RDNSS is provided via SLAAC, the TV will have empty IPv6 DNS servers
- IPv6 internet can still work via IPv4 DNS

## Notes

Philips 32PFS6805/12 Saphi OS uses SLAAC for IPv6, but does not use DHCPv6. If no RDNSS is provided via SLAAC, IPv6 DNS servers will be empty on the TV. IPv6 internet is accessible via IPv4 DNS, though.
