# Use Online Office 365 as a Google Chrome PWA
1. Access [Microsoft OneDrive](https://onedrive.live.com)
2. Create a mock document for Word, PowerPoint and Excel
3. When you are in the Word document change the icon to a higher resolution icon(F12, then go to head, find the icon url and put an url for an icon with a higher res)
4. Save the page as a shortcut(More tools + Create shortcut)
5. Do this for PowerPoint and Excel document
6. When you open an Office 365 url containing a document you will now have the option to select in which app to open
