# Max Tablet Density

This is the max density at which the tablet UI is loaded on apps on Android.

| Resolution | Density |
| --- | ---: |
| 1280 x 720 | 192 |
| 1366 x 768 | 204 |
| 1920 x 1080 | 288 |
| 2560 x 1440 | 384 |
| 3840 x 2160 | 576 |
